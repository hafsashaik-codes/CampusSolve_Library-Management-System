# CampusSolve Library Desk - FastHTML Edition

## Project Description
CampusSolve is a browser-based Library Record Management Application developed using Python and FastHTML.

It helps manage books, student details, book issues and returns.

## Features
1. Library Dashboard
2. Add and View Books
3. Student Registration
4. Issue Books
5. Return Books
6. Transaction History
7. Library Statistics
8. Export Book Records to CSV
9. Automatic Data Storage
10. Sample Demo Data

## Technologies Used
- Python
- FastHTML
- HTML
- JSON
- CSV
- File Handling

## Installation
Open the VS Code terminal and execute:

python -m pip install python-fasthtml

## How to Run
Execute:

python campus_solve.py

Open the browser and visit:

http://localhost:5001

## Demo Instructions
1. Open the Dashboard.
2. Click Load Demo Data.
3. View the sample books and students.
4. Try issuing and returning a book.
5. Open Reports to view library statistics.

## Sample IDs
Book ID: BK301
Student ID: ST301

## Data Storage
Records are stored in library_records.json.
Exported book records are saved as books_export.csv.
